## 2. 原方案偏差

原 PRD 把“用户在少量区域指定高度，再平滑叠加”设为核心基线，AI 重建只列为增强。这种实现可验证网格封闭、尺寸和导出，但无法单凭这些能力满足用户要求的细致、可辨认照片浮雕。

以硬编码/人工区域构造的粗起伏，只能作为几何单元测试或临时编辑辅助，不能再作为照片重建产品主路径的验收产物。当前样品效果用户已明确表示不满意，不能继续把该路线的相似度记为仅等待用户确认。

高度场可以是最终浅浮雕的存储/压缩表示，但不能先把算法能力锁死在少量平滑基函数。允许选择能提供质量的重建和细节恢复方法，再验证结果是否适合加工与表示。

## 3. 修正后的目标流程

1. 原始照片/用户图像 → 前景与主体处理，保留身份、五官及纹理参考。
2. 恢复连续形体：眼眶、眼睑、鼻梁/鼻尖、嘴唇、脸颊及主体空间关系。用户可查看无贴图模型。
3. 恢复表面几何细节：头发/毛发、褶皱等，结合形体表达；可生成结构线和细节图作为辅助，不要求先得到一张线稿就能唯一反推出所有三维形体。
4. 形成用户认可的高质量浮雕母版，保留可编辑源、真实几何和可选颜色贴图。首先达到参考的细节表现方向，再讨论生产规模。
5. 从母版设计配套阴阳模：保留皮厚间隙、分模/脱模方向、过陡与倒扣检查、支撑及定位。不是复制两份 OBJ 或简单正负缩放。
6. 打印、试压，确认形体及细节能否在皮革上保留；合模动作不能等同于已经验证可制造。

颜色纹理（JPG/UV）与几何纹理（实际凹凸）必须分开。前者用于展示/上色参考，后者才会进入打印模具。原图提取的黑白颜色变化不能无条件解释成凹凸深度。

## 4. 立即调整的开发优先级

- 保留已通过的本地环境、渲染、单位与文件导出基础；不重装依赖、不删除已有试验。
- 暂停沿原粗区域凸起路线扩展产品 UI、复杂模具和材料系统，先做参考对照。
- 首个任务是导入并展示现有 OBJ，提供有贴图/无贴图、正/斜/侧视对比，确认用户认可的目标母版。
- 第二个任务才是选择/验证照片到细致浮雕的候选算法。不得把导入参考 OBJ 伪装成从照片生成；不得用贴图遮住几何不足。
- 如有原始照片，应优先使用；当前 test1.png 是软件截图，无法据它声称复现原文件完整制作链。没有原片仍可分析参考模型，但应记录输入限制。
- 候选算法需要真实案例验证；本说明不承诺某个模型能一键得到参考品质，也不在未实测前锁定模型或下载大型权重。
- 先交付对照结果和缺陷清单供用户判断，再把通过的路线写回全面 PRD。

## 5. 新的最低验收方向

- 去掉颜色贴图后，五官与主要毛发/褶皱细节仍可辨认。
- 正面、斜侧和侧视形体均合理；结果不能仅是轮廓挤出或几个平滑鼓包。
- 导出 OBJ/STL 后重新加载，细节仍在实际网格中。
- 报告逐项列出参考具备而生成结果缺失的结构，并记录人工介入，不以水密/面数/尺寸达标替代效果验收。
- 先验收几何母版，再验收模具设计，最后验收实物；三项不得混为一个“成功”。
