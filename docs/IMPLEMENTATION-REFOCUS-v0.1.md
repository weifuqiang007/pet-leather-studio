# 精细浮雕母版与配套模具：收敛实施路径 v0.1

日期：2026-09-20。本文优先于 PRD v1.1 中旧的区域凸起路线和推进顺序；工程规范仍沿用。

## 1. 代码现状与问题

本次改动前，正式 src 只有环境、日志、入口与错误类型；可见几何算法位于 experiments/relief_spike，以人工多边形叠加平滑高度生成实体。它验证了数值/导出，但用户已否定其视觉效果，不能继续当作产品建模算法。现有 PySide6/PyVista 本地环境与渲染可复用，旧实验和测试保留用于历史，不删除。

目标是：照片 → 细致浮雕母版 → 配套阴阳模 → 湿皮试压。软件须区分照片重建能力、母版几何质量、候选模具几何、实际皮革转印，四项不能互相代替。

## 2. 收敛实施顺序

### A. 本次实现：母版到模具的可验证基础

1. 新建本地工程并导入 OBJ/STL/PLY 精细母版；保存原文件与 SHA-256，默认不使用照片贴图。
2. 在桌面界面以中性材质查看正面、侧面和斜视；以用户已有 reference OBJ 检查细节真实存在。
3. 显式输入目标宽度、最大浮雕深度、Z 向间隙、底板厚度和采样分辨率。
4. 选择 +Z 作为当前仅支持的成形方向，对可见上表面采样生成候选配套模具。
5. 导出阳模 STL、阴模 STL、高度数据和参数清单。装配坐标统一，皮革空间可剖面检查。
6. 母版和每次模具生成均形成不可变版本；回退仅切换 active revision，旧产物不删除。

本次模具是“Z 向间隙、矩形块、无定位销”的几何试验候选，非自动生产认证。用户必须明确接受 +Z 上表面投影会忽略背面/倒扣，并确认朝向。未进行倒扣自动检测时不得标为无倒扣。外圈/挂环与人物母版分开选择，不能默认把整个挂件压入牛皮。

### B. 下一步：照片重建质量实验（独立质量门）

使用原始照片和已认可母版作为参考，比较候选重建方法。输出中性材质真实几何，不可贴图作弊；主要五官、毛发、衣纹须由用户评审。区域凸起只能保留为历史/辅助，不能作为成功回退算法。尚无经验证的本地模型时，界面明确“不提供照片自动重建”，不下载未知模型或返回假结果。没有原照片时记录 test1.png 是软件截图的输入限制。

### C. 后续

母版通过后完善等法向皮厚、定位、限位、支撑和局部精度；再接实物试压与扫描质检。FreeCAD、FEM、自动补纹设备继续留后续，不阻塞 A/B。

## 3. 参数标准

| 参数 | 当前可调 | 影响与约束 |
|---|---|---|
| 目标宽度 width_mm | 是 | 5–300 mm；XY 按母版比例缩放，不把 OBJ 数字擅自当毫米 |
| 浮雕最大起伏 depth_mm | 是 | 0.05–20 mm；按采样上表面范围映射，Z 与 XY 比例可不同，改变原几何比例必须显式记录 |
| Z 向皮革间隙 gap_mm | 是 | 0.05–10 mm；是设计试验间隙，不是实际皮革推荐厚度或压缩预测 |
| 两模背板厚度 backing_mm | 是 | 1–30 mm；纯几何值，不代表材料承载能力 |
| 网格长边 grid_size | 是 | 32–512；当前候选阶段限额，防百万面参考导致内存失控；不是生产精度承诺 |
| 需保留最小特征 feature_mm | 是 | 0.05–5 mm；至少四个采样间隔初筛，不满足时输出 sampling_sufficient=false，只能称低精度候选 |
| 开模方向 | 当前固定 +Z | 不自动猜；用户必须确认正面朝 +Z；其他方向须先在 Blender 中生成新的母版版本 |
| 单位/算法版本/源 hash | 不可手改 | 由程序生成、用于追溯；输出单位统一 mm |
| 母版与模具历史文件 | 不可覆盖修改 | 修改产生新版本，回退切指针 |
| 成形压力/保压/干燥/材料强度 | 本次不计算 | 需要实物与材料数据，不能伪造默认值 |
| 纹理真实性/人物相似度 | 不是可调分数 | 由网格与人工评审确认，测试通过不能代替 |

80 mm 工件保留 0.2 mm 特征需约 1601 点以上长边采样。当前 512 限额明确不足，必须显示风险；不要把此候选称为精细生产模具。后续引入流式/分块采样与公差验收后再放开高分辨率。

## 4. 实现逻辑与注意点

- 从精细母版取上表面，不重新用粗区域构造人物。参考几何不得改写。
- 使用真实网格相交采样，不从截图亮度生成深度。
- 无交点区用可见表面最低高度形成平背景，保存覆盖掩码和覆盖率；这会补齐矩形背景，属于显式加工设计，不伪称原始几何。
- 下凸模顶部 = backing + H；上凹模底部 = backing + H + gap；下底为 0，上顶为 2*backing + max(H) + gap。上下接触面在同一装配坐标，因此 Z 间隙恒为 gap。
- 上模导出保留装配坐标，切片打印时可能需旋转放置；两份 STL 不是在同一位置重叠打印。
- 光滑渲染仅辅助查看，不能创建实际细纹。候选网格写文件后重新读取，检查封闭、正体积与有效数值。
- 不承诺此阶段处理倒扣、等法向间隙、陡壁、挂环孔等复杂拓扑；用户投影确认在 manifest 留记录。
- 应用 GUI 只管输入/展示；任务后台进程运行，取消不写成功版本。SQLite 由持有工程写锁的任务进程提交，GUI 仅刷新读取结果。
- 原始几何通过受控适配器加载；不执行 OBJ/PLY 中任何脚本、不访问远程材质。

## 5. 两种版本与回退

### 代码版本

- 开发分支：codex/mold-refocus-v0.1。
- 改动前 Git 标签：baseline-before-mold-refocus-20260920（指向此前已提交 HEAD）。
- 标签不含当时未提交的纠偏文档；完整工作文件另备份于 runtime/backups/20260920-141309/working-tree.zip，hash 清单为 manifest.json，Git 历史为 history.bundle。
- 回看旧代码优先另建目录：`git worktree add ../pet-leather-studio-baseline baseline-before-mold-refocus-20260920`。不建议在当前有改动的目录执行 reset --hard。
- 本次发布标签为 mold-workbench-v0.1.0，可通过 git show 查看对应 commit。切换代码前先保存未提交改动；数据版本与代码版本分开管理。

### 数据版本

- 每个工程保存 project.sqlite、revisions/<uuid>/manifest.json 与产物。
- 版本包括 source/import 或 mold，parent_id、算法版本、参数、输出 hash、创建时间。
- 每次生成新目录，不能覆盖旧目录；失败/取消不成为成功版本。
- GUI/CLI 可列出版本、激活旧版；以旧版继续生成时新版本 parent 指向旧版，形成分支历史。
- 程序回退到更旧 schema 时拒绝写入，不自动降级数据库。重要原照片和模型另做常规备份；Git 不保存 images/workspace 大文件。

## 6. 本次验收

- V01：导入参考 OBJ，保持原文件 hash 不变，无贴图可查看真实细节。
- V02：参数越界、非有限值、非支持格式明确拒绝。
- V03：解析平面/坡面高度生成两模，封闭、正体积，装配间隙与输入一致。
- V04：生成两次不同参数形成两个版本，回退旧版后产物 hash 不变。
- V05：失败/取消不改变当前版本；进程失败可重试，不覆盖成功数据。
- V06：低采样时醒目标注，只导出候选，manifest 明示缺失能力及 source_import（非照片重建）。
- V07：实际用户 OBJ 跑通一组候选并产出三维视图；这只能证明导入到候选的链路，不能标为已实现照片到母版。
- V08：Ruff、mypy(domain/application)、单元/架构测试通过；真实 GUI 打开、导入展示、正常关闭有记录。

## 7. 当前与旧 PRD 的关系

本路径先交付有版本管理的参考母版/模具候选工作台，而不是完整旧版 R1。旧环境/日志/测试保留。相似度与物理验收保持未通过，不自动勾选旧 M0.5。新工作不证明照片重建已经完成，也不恢复旧区域凸起方案的产品地位。
