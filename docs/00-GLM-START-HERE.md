## 第一轮工作

1. 检查仓库现状与适用的 AGENTS.md，保留已有业务代码及用户修改。
2. 先实施 M0 环境与骨架，以及 M0.5 脚本级算法验证；两者可在依赖允许时交错推进。

5. 无人评审时标 pending，不替用户确认相似度；仍可推进不依赖评审结果的基础工作。
6. 再按 PRD 实施 M1；不要一次铺开 M2–M6 的空壳实现。

## 必须保持的边界

- Python Qt 绑定统一 PySide6；无需搭建浏览器前后端。
- 模型、依赖与项目下载缓存放在本仓库约定的本地目录，不安装到全局 Python。
- 使用用户已有 Blender，先检测；当前不安装 FreeCAD，不强制安装有限元求解器。
- 没有 AI 权重、网络或扫描仪时，人工标注与基础浮雕导出仍须可用。
- 相似度、实际压制效果、扫描精度不能由代码测试或合成数据虚报通过。
- 不采购、不上传照片、不连接机械臂发指令。
