# ADR-0001：PRD 评审后的范围与实现约束

- 日期：2026-09-18
- 状态：本次文档修订采用；实现效果待里程碑验证
- 关联：[PRD v1.1](../PRD.md)、[评审答复](../PRD-review-response.md)

## 决策

1. 保留 PySide6 本地桌面与离线优先，增加已定义的三维查看退路。
2. 增加 M0.5 脚本算法验证，正式 M1 继续最小 SQLite/revision，不增加 JSON 生产存储迁移阶段。
3. R1 统一高度场，毛纹在高度层计算，生产采样按真实尺寸/最小特征确定；外部 Blender 网格必须验证能否回流。
4. 增加人工形体评审、独立物理验证状态、草稿恢复与 CI 质量门。
5. FreeCAD、FEM、机器指令仍不属于当前必装能力，所有新下载物本地化要求不变。

## 取舍

高度场限制任意曲面编辑，但减少 R1 复杂布尔与性能风险；M0.5 增加早期几天验证，降低后续围绕不合格形体搭系统的风险。相似度人工门可能等待负责人反馈，等待期间允许通用基础设施推进，不能虚报通过。规模估计是规划区间，不是对 AI 编程效率或可售产品时间的保证。
