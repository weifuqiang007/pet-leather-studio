# ADR 0002：以精细母版和配套模具收敛当前实现

日期：2026-09-20；状态：已采用。

用户否定区域凸起效果，并提供真实精细 OBJ 参考。照片重建与模具生成分为两个独立质量门；当前先实现参考母版到模具链路，不以粗形体作为重建回退结果。

领域层定义参数及端口；应用层协调导入/生成/历史；基础设施层负责 VTK 采样、文件、SQLite 与锁；算法层生成实体；PySide6 展示层调用后台 CLI，bootstrap 组装依赖。

所有新产物写独立修订目录并保存 hash。工程级写锁串行化发布，失败不切换当前版本。代码以 Git 标签保存，数据以修订及 parent_id 保存；两者不可混为一谈。

本轮使用明确的 +Z 上包络和恒定 Z 间隙，属于有边界的几何候选。固定采样上限并报告不足，不隐瞒纹理损失。等法向皮厚、倒扣检查、定位、压力仿真和扫描闭环仍未实现。

旧 ADR 0001 的工程约束继续适用；其与本决策冲突的建模基线与阶段顺序被替代。
